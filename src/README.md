
# 실시간 커머스 콘솔 프로그램

이 프로그램은 **콘솔 화면에서 상품을 둘러보고 정보를 확인할 수 있는 쇼핑 프로그램**입니다.  
마우스 없이 **숫자 입력만으로** 카테고리와 상품을 선택할 수 있습니다.

---

## 프로그램 소개

프로그램을 실행하면 사용자는 다음과 같은 일을 할 수 있습니다.

- 여러 카테고리 중 하나를 선택한다
- 선택한 카테고리의 상품 목록을 본다
- 상품을 선택해 상세 정보를 확인한다
- 이전 화면으로 돌아가거나 프로그램을 종료한다

복잡한 회원가입이나 설정 없이  
**숫자 입력만으로 간단하게 사용할 수 있는 구조**입니다.

---

## 프로그램 실행 방법

1. 프로그램을 실행합니다.
2. 화면에 표시되는 메뉴 번호를 보고 숫자를 입력합니다.
3. 엔터 키를 눌러 선택을 완료합니다.

---

## 사용 흐름 (사용자 기준)

### 1. 메인 화면

프로그램을 실행하면 아래와 같은 화면이 나타납니다.

[ 실시간 커머스 플랫폼 메인 ]

전자제품
의류
음식
종료

- 보고 싶은 카테고리의 번호를 입력합니다.
- `0`을 입력하면 프로그램이 종료됩니다.

---

### 2. 상품 목록 화면

카테고리를 선택하면 해당 카테고리의 상품 목록이 나타납니다.

[ 전자제품 상품 목록 ]

LG그램 노트북
Galaxy S26 Ultra
AirPods Pro
뒤로가기

- 상품 번호를 입력하면 해당 상품의 상세 정보를 볼 수 있습니다.
- `0`을 입력하면 메인 화면으로 돌아갑니다.

---

### 3. 상품 상세 화면

상품을 선택하면 상세 정보가 표시됩니다.

[상품 상세]
상품명: Galaxy S26 Ultra
가격: 2,260,000원
설명: 삼성 최신 스마트폰

- 상품의 이름, 가격, 설명을 확인할 수 있습니다.
- 엔터를 누르면 다시 상품 목록 화면으로 돌아갑니다.

---

### 4. 다시 선택 or 종료

사용자는 언제든지

- 뒤로 가서 다른 상품을 선택하거나
- 다른 카테고리를 선택하거나
- 프로그램을 종료할 수 있습니다

프로그램은 종료를 선택할 때까지 계속 실행됩니다.

---

## 잘못된 입력 처리

사용자가 아래와 같은 입력을 했을 경우에도 프로그램이 종료되지 않습니다.

- 숫자가 아닌 값을 입력한 경우
- 존재하지 않는 번호를 입력한 경우

이 경우 안내 문구가 출력되고 **다시 입력할 수 있는 기회가 제공됩니다.**

---

## 이 프로그램의 특징

- 숫자 입력만으로 조작 가능
- 복잡한 메뉴 없이 직관적인 화면 구성
- 실수해도 프로그램이 멈추지 않음
- 언제든 뒤로 가기 가능

---

## 이런 사람에게 적합합니다

- 콘솔 프로그램을 처음 접하는 사용자
- 숫자 입력 기반 메뉴 연습을 원하는 경우
- 간단한 쇼핑 구조를 이해하고 싶은 경우

---

## 마무리

이 프로그램은  
**“상품을 선택하고 정보를 확인하는 과정”**에 집중한 콘솔 쇼핑 프로그램입니다.

추후 확장으로 장바구니, 결제 기능 등을 추가할 수 있도록  
기본 구조를 단순하고 명확하게 설계했습니다.
